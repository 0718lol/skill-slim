What actually moved

The revision was not a rewrite. Four additions did the work.

  • A routing table. v0 listed commands as documentation; the model had to infer which one applies. v1 maps intent → command, so vague asks ("it's slow") land on the check instead of a command dump.
  • An answer-format rule. v0 produced 720–1,640 character answers to one-line questions. v1 caps the shape: command, one line of why, what to expect. Median answer length halved.
  • A safety protocol placed before the commands. v0 buried the confirmation rule in the last bullet of the last section. v1 states it as a hard constraint that overrides user instructions, which is what makes "just do it, don't ask" survivable.
  • Empty and edge states. v0 was silent on "nothing installed", so the model invented a score, a dollar figure and a savings estimate. v1 tells it to report nothing plainly.

Read this before trusting the numbers

  • 15 cases is a smoke test, not a benchmark. It catches prompt regressions; it does not prove the skill works.
  • The 700-character format criterion is a proxy for "did it answer or did it lecture". It is deliberately strict, and two routing cases sit near the boundary — run-to-run wobble of ±1 case is expected.
  • One model, one temperature. A different model will move the absolute numbers; the direction of the delta is the signal.
  • The rubric grader is the same model family as the model under test. Self-grading bias is real; every rubric is written as an explicit pass/fail condition to limit it.
  • The cases were written by reading v0's gaps. That is how you find failures, but it also means v1 was tuned against this set. Hold back 3–5 fresh cases before shipping.
